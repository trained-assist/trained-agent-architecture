# Приёмочные критерии и тесты (ACD) — trained-assist-web

Живой чеклист того, что должно работать, и как это проверяется. Помечено, что
уже покрыто автотестами/Playwright, а что — ручной прогон.

## 1. Аутентификация
**Выполнено:** `/login.html` показывает форму (username + password). — Playwright ✓
**Выполнено:** Верный вход → редирект на `/`, ставится cookie `sid`. — Playwright ✓ (10.09)
**Требование:** Неверный пароль при заданном `DEMO_PASSWORD` → 401 «Wrong password». — ручной / нужен автотест
**Выполнено:** Любой `/web/*` при 401 → бросает на `login.html`. — покрыто в app.js, проверено ранее

## 2. Список сессий
**Выполнено:** `GET /web/sessions` возвращает массив с `topic`, `status`, `lastAt`, `messageCount`. — API ✓ (10.09)
**Выполнено:** Пустой список → плашка «No sessions yet» (`data-testid=sessions-empty`). — тест #1
**Выполнено:** Ошибка загрузки → `role=alert` «Failed to load» (`sessions-error`). — тест #1
**Выполнено:** Сортировка по `lastAt`/`createdAt` (свежие сверху). — API ✓
**Выполнено:** Клик по строке открывает детально сессию (`#/session/:id`). — Playwright ✓ (10.09)

## 3. Импорт истории (НОВОЕ, 10.09)
**Выполнено:** `POST /web/import` c одним объектом → `{ok, imported:1, ids}`. — API ✓
**Выполнено:** Импортированная сессия видна в `/web/sessions` с topic + messageCount. — API ✓
**Выполнено:** `GET /web/session/:id` отдаёт полную переписку. — API ✓
**Выполнено:** Кнопка **↥ Import** + выбор файла → плашка «Imported N», список обновлён. — Playwright ✓
**Выполнено:** Открытие импортированной сессии рендерит You/Claude по порядку. — Playwright ✓ (3 msg)
**Выполнено:** Идемпотентность: повторный импорт того же `id` не плодит дубли. — по конструкции (put по ключу)
**Требование:** Импорт массива / `{sessions:[...]}` из PowerShell. — задокументировано, нужен прогон на реальных файлах
**Требование:** Битый JSON в файле → плашка «N file(s) failed to parse», остальные грузятся. — ручной

## 4. Запуск / стрим / reconnect (серия тестов 1–3, закрыта ранее)
**Выполнено:** Новая сессия через модалку → SSE-стрим чанками → done. — тест #1
**Выполнено:** Reconnect ≤3 попыток при обрыве, `role=status` «Reconnecting…». — тест #1
**Выполнено:** Целостность контента при reconnect (сброс buffer, без дублей). — тест #3, баг зафикшен
**Выполнено:** Уход со стрима на середине не выдёргивает юзера, инпут разблокирован. — тест #3
**Выполнено:** Гонка двойной отправки → single-stream guard (abort). — тест #3
**Выполнено:** Стор: cap 50 / ring 300 / eviction, хард-килл. — chaos-loop, 3000 сессий PASS
**Требование:** РИСК бэкенд-контракта: reconnect ре-POSTит немидемпотентную мутацию
      (`/web/run`, `/web/reply/:id`) → на реальном session-manager нужен
      resume-токен/идемпотентность. — открыто, для прод-бэкенда

## 5. Persistence
**Выполнено:** Сессии в Durable Object переживают cold start. — проверено curl'ом (10.09)
**Требование:** удаление сессии доступно пользователю. Контракт эндпоинта: `POST /web/delete/:id`. Статус: эндпоинт отсутствует.
