# Trained Agent Architecture

Общая целевая архитектура Trained Assist: ориентир для эпиков и проверки направления разработки.

## Документ

[Целевая архитектура бэкенда — ARCHITECTURE.md](ARCHITECTURE.md)

Текущая версия: **0.1, draft для согласования**. Документ разделяет требования владельца, факты из исходников, предложения и открытые решения. Схема приведена в Mermaid.

## Как использовать

- Привязывать эпики к архитектурным блокам `A01–A13` и инвариантам `INV-01–INV-13` из документа.
- Указывать текущий пробел, целевой контракт и проверяемые доказательства приёмки.
- Ответы на открытые вопросы переносить в согласованные решения; обновлять историю решений и версию документа.
- При повторной сверке кода обновлять проверенные ревизии и факты реализации.

Статусы выполнения задач вести в issues или трекере; этот репозиторий хранит архитектуру и решения.
